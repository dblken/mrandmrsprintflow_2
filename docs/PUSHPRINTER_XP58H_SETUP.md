# PrintFlow PushPrinter + XP-58H setup

PrintFlow implements the native PushPrinter v3.1.0 contract and a polling fallback. The native Windows app uses Pushy notifications, so a Pushy application is required for a self-hosted PrintFlow installation.

## Server setup

1. Run `php database/migrate_receipt_printers_pushprinter_20260816.php` or import `database/receipt_printers_pushprinter_20260816.sql`.
2. Create a Pushy application for PrintFlow.
3. Add its Secret API Key to the production environment as `PUSHY_API_SECRET`.
4. In Admin > Settings > XP-58H Receipt Printing, create the printer and copy the generated API key. It is displayed once.
5. Queue a test receipt after the Windows agent is connected.

## Windows and PushPrinter v3.1.0

1. Install a working XP-58H or generic ESC/POS Windows driver. Resolve "Driver is unavailable" first and confirm a Windows test page prints.
2. Set the Windows printer paper to 58mm, with approximately 48-50mm printable width and zero/minimum margins.
3. In PushPrinter settings, set the API URL to the `PushPrinter API Base URL` shown in PrintFlow Admin settings.
4. Set the Pushy App ID to the App ID belonging to the same Pushy application as `PUSHY_API_SECRET`. Restart PushPrinter so it obtains a device token for that app.
5. Create a PushPrinter printer with:
   - Printer Name: `PrintFlow POS Receipt`
   - API Key: the one-time key generated by PrintFlow
   - Number of Copies: `1`
   - Printing Type: `Windows Shared Printer (ESCPOS)`
   - Windows Shared Printer Name: the exact XP-58H share name
6. Enable automatic startup and confirm PushPrinter shows connected.

PushPrinter stores these application settings in `%APPDATA%\pushprinter\config.json`. For a custom/self-hosted profile, `config.v2.appApiUrl` must be the PrintFlow base URL and `config.v2.pushyAppId` must match the custom Pushy application. Keep the generated printer API key private.

## HTTP contract

The native agent uses these extensionless endpoints under the configured API base URL:

- `GET /printing/pushy/register-device?deviceToken=...`
- `POST /printing/client/order-to-escpos`
- `GET /printing/jobs/update/status`
- `POST /printing/jobs/update/error`

The fallback agent endpoint is `/public/api/printer/jobs.php`; it supports polling and acknowledgement with the same Bearer API key.

## Receipt tuning

Start with 32 characters per line. Use 42 only when the XP-58H driver/character density prints it without clipping. The server emits raw ESC/POS initialization, compact text, feed lines, and cut commands; long item and customization text is wrapped before printing.
